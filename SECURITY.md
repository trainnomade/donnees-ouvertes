# Sécurité

## Signaler une faille

Si vous trouvez une faille de sécurité sur trainnomade.fr, sur l'API `api.trainnomade.fr` ou dans ce dépôt, merci de
**ne pas ouvrir de ticket public** : utilisez le bouton « Report a vulnerability » de l'onglet
[Security](https://github.com/trainnomade/donnees-ouvertes/security) de ce dépôt (signalement privé), ou écrivez à
contact@trainnomade.fr avec l'objet « Sécurité ».

Merci d'indiquer l'adresse concernée, les étapes pour reproduire et l'effet constaté. Nous répondons sous 7 jours et
vous tenons informé jusqu'à la correction. Merci de ne pas publier la faille avant sa correction, de ne pas dégrader le
service (pas de test de charge) et de ne consulter aucune donnée qui ne vous appartient pas.

## Ce que contient ce dépôt

Uniquement des données ouvertes et leur documentation : aucun code de production, aucune donnée personnelle, aucun
secret. Les fichiers sont publiés par un processus automatique après des contrôles bloquants (nombre de lignes, dates,
valeurs plausibles) ; en cas d'échec, la version précédente reste en place.

---

**English** : please report vulnerabilities privately through the "Report a vulnerability" button of the Security tab,
or by email to contact@trainnomade.fr (subject "Security"). We answer within 7 days. This repository only holds open data
and documentation: no production code, no personal data, no secrets.
